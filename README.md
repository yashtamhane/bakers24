# Baker’s 24 — Proposal Website Design Handoff

**Status:** specification for review. **Do not implement until explicitly authorized.**

## Source of truth
- `references/approved-design.png` is the **user-approved** visual direction (1536×1024 collage). Preserve its atmosphere and composition, not its invented products or impossible UI details.
- `DESIGN_SYSTEM.md` and `PAGE_BLUEPRINTS.md` translate that collage into practical, accessible layouts.
- `CATALOG.json` holds screenshot-derived **reference** prices, not verified live prices.
- `CONTENT.md` records business information, source confidence and editorial policy.
- `IMPLEMENTATION_PLAN.md` is the staged instruction set for Claude Code **after approval**.

## North star
A premium patisserie experience that feels like entering a beautifully curated boutique, but lets a first-time smartphone user order a cake quickly. Mobile is an intentionally art-directed experience, not a shrunk desktop site.

## Non-goals for proposal
No real checkout/payment processing, no inventory promises, no unapproved production deployment, no invented customer testimonials, no automatic Instagram scraping, no unverified promotional pricing.

## Review checkpoints
Approve mobile home, mobile menu, desktop home, product detail, custom-cake flow, seasonal presentation, and actual order message. Images are conceptual where explicitly indicated.
