# Page Blueprints

## 1. Mobile homepage — build first
Dark cinematic, almost full-viewport hero. Small elegant logo and menu/search; one clear serif headline (“Moments Taste Better Here.”), one-line description, one prominent `Explore Cakes` button. Cake photograph is the hero, not a busy background of stickers. Below the fold: three curated doors (`Celebration Cakes`, `Custom Cake Atelier`, `Seasonal Edit`) and a quiet footer. Only one active seasonal promotion. Avoid horizontal text carousels, unnecessary decorative quotes, and crowded icon rows.

## 2. Mobile cake menu — build second
Deep cocoa/black-cherry backdrop, premium collection heading and subtle food texture. Category chips (`All`, `Chocolate`, `Truffle`, `Fruit`, `Rasmalai`, etc.) and search. Rich horizontal cake rows: image, title, verified/demo price, one obvious view/select affordance. No white generic tile grid. Clearly indicate 0.5 kg where applicable. Do not assume category or allergen information from name alone. Include empty search result and loading/error states. Filters must be operable by touch and keyboard.

## 3. Desktop homepage
Match approved collage's split hero and restrained typography; single primary CTA. Curved transition to warm ivory `For Every Beautiful Moment` gallery. Three editorial collection tiles; one seasonal module; small curated real-work gallery; restrained customer feedback; footer with location and contact. Prioritize breathing room.

## 4. Cake detail
Large authentic/conceptual cake imagery; name, 0.5 kg reference price, concise description only if supported; quantity/size only where actually offered or clearly marked `Ask bakery`. Personalization message and desired date fields; `Order on WhatsApp` assembles editable prefilled message. Never imply successful purchase or guaranteed availability.

## 5. Cake Atelier
Curated authentic portfolio by birthday, wedding/anniversary, kids/theme, milestones. Full-screen image detail, optional reference note, `Request Something Similar` action. Ask for occasion, approximate size, desired date, notes, optional image upload (for demo, avoid pretending a WhatsApp URL attaches a local image). Clearly state custom prices are estimates/quoted by shop.

## 6. Seasonal Edit
Theme-led campaign screen with one featured photo, few products and simple CTA. Christmas/New Year/Valentine's/Mango are demo templates, not live offerings. Admin/editor workflow can be conceptual in proposal; campaign scheduling requires later implementation. Expired promotions must never appear as active.

## 7. Guided custom-cake inquiry
3–4 small steps: occasion → reference design/size → flavor/details/date → review and WhatsApp. Allow `Not sure` for optional choices. Only offer actual confirmed flavor/size choices; otherwise free text. Show progress and back button; preserve inputs; review message before opening WhatsApp.

## 8. About/contact
Address, Instagram, WhatsApp, email, hours flagged pending verification, same-day delivery phrased as `Ask about same-day delivery` until coverage/cutoffs confirmed. Maps link to verified shop location. Keep all contact actions accessible.

## 9. Desktop menu and responsive behavior
Use an editorial 2-column or spacious list interpretation of mobile menu, preserving premium backgrounds and legibility. Never turn mobile cards into an ordinary marketplace grid. Test 320, 375, 390, 430, 768, 1024 and 1440px widths.
